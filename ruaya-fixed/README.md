# رؤية - Ruaya Platform

منصة تعليمية لطلاب البكالوريا المصرية

## التحديثات في النسخة دي (Fixed)

### 1. الأمان
- كلمات السر بقت **مشفرة** باستخدام `bcryptjs`
- مفيش باسورد بيتخزن نص عادي تاني

### 2. CORS
- السيرفر بقى يسمح لدومينات Vercel و Railway و localhost

### 3. التقدم
- المستخدم الجديد بيبدأ من **0%** و **الأسبوع الأول**
- التقدم بيتحسب حسب المهام اللي خلصها فعلاً

### 4. تنضيف
- اتشالت ملفات MongoDB القديمة (User.js + userController.js + userRoutes.js)
- المشروع دلوقتي SQLite فقط

---

## طريقة التشغيل

### Backend (Railway)
1. ارفع مجلد `backend`
2. تأكد إن `package.json` فيه `bcryptjs`
3. اعمل Deploy

### Frontend (Vercel)
1. ارفع ملفات الـ Frontend
2. تأكد إن `API_BASE_URL` في `app.js` واصل على رابط Railway بتاعك

---

## ملاحظات مهمة

- SQLite على Railway ممكن تضيع البيانات لو السيرفر عمل Restart كتير.
- الأفضل لاحقاً نحول لـ PostgreSQL.
- المستخدمين القدامى اللي الباسورد بتاعهم مش مشفر مش هيقدروا يدخلوا → لازم يسجلوا من جديد أو نعمل سكريبت تحويل.
