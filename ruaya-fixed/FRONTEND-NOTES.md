# ملاحظات تعديل الفرونت إند

## 1. في ملف `app.js`

### غيّر دالة حساب التقدم عشان المستخدم الجديد يبدأ من صفر:

ابحث عن دالة `updateWeeklyProgress` و`calculateStats` وتأكد إن:

- لو `completedTasks` فاضي → التقدم = 0%
- الأسبوع الحالي = 1
- النقاط = 0
- السلسلة = 0

### تأكد من الرابط:

```js
const API_BASE_URL = 'https://ruaya-backend-production.up.railway.app/api';
```

## 2. في `dashboard.html`

- شيل أي أرقام ثابتة زي 68% أو الأسبوع التالت
- خلي القيم الافتراضية:
  - إنجاز الشهر: 0%
  - يوم متواصل: 0
  - من أصل 600: 0
  - مهام متبقية: حسب اليوم

- في مسار التقدم (path-nodes):
  - الأسبوع الأول = current
  - الباقي = locked
